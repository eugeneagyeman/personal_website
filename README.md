# Personal Website

Source for [eugeneagyeman.io](https://eugeneagyeman.io): a static Astro site on
Cloudflare Workers assets. Node 26, pinned in `.nvmrc`.

```sh
npm install
npm run dev       # http://localhost:4321
npm run build     # build to ./dist/ and refresh CSP hashes
npm run preview   # serve the build
npm run shots     # screenshot every route (needs dev running + Playwright's Chromium)
```

## Where things live

- `src/lib/site.ts`: name, emails, links, and `availability` (printed by the shell's `status`; keep it true).
- `src/lib/commands.ts`: the header name shell's commands.
- `src/data/cv.json`: the CV. The PDF in `public/` comes from Overleaf; update both.
- `src/content/blog/`: posts as `.md`/`.mdx` with `title`, `description`, `pubDate`.
- `docs/`: `DESIGN.md` (visual system, the source of truth) and `PRODUCT.md` (audience, voice, constraints).

## Gotchas

- CSP hashes in `public/_headers` are generated by `npm run build`. Commit them after editing any script.
- Stop `npm run dev` before running `npm run build`.
- Use ASCII `->`, not `→`: the self-hosted font has no arrows.

## Deploying

Pushing to `main` builds and deploys via `.github/workflows/deploy.yml`, after
approval on the `production` environment (which holds `CLOUDFLARE_API_TOKEN` and
`CLOUDFLARE_ACCOUNT_ID`). Manual deploy: `npx wrangler login && npm run deploy`.
